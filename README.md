# XingCe AI Lab · 行测思维实验室

面向国考地市级的本地学习工具：逐步教学、原图阅读、来源追溯、错题复习、答题用时与模块正确率。使用 Next.js、React、TypeScript、Prisma / SQLite、Zod、KaTeX、PDF.js 和 Mammoth。

**本公开仓库只包含程序代码，不包含历年题库、购买的笔记、试卷原件、学习记录或 API 密钥。** 首次安装为空库，请通过「资料与设置」导入自己有权使用的资料，并人工核验。代码中的原创演示题明确标记为模拟题，不冒充真题，也不默认导入。

## Windows 快速开始

安装 Node.js 22.13+（建议 24 LTS）与 Git，下载本仓库后双击 **开始学习.bat**。启动器安装依赖、初始化本地数据库并打开浏览器。首次启动需要联网安装依赖。保留启动窗口，按 Ctrl+C 退出。

也可手动运行：

```powershell
npm ci
Copy-Item .env.example .env
npm run setup
npm run build
npm start
```

打开 http://127.0.0.1:3000 。重复启动不清空已有记录。

## 功能与边界

- PDF / DOCX 文本提取、题目边界与选项解析、人工审核、重复检测及修订追溯。扫描件 OCR 尚未实现，复杂版式必须对照原件。
- 按模块、年份、考点练习；记录逐题耗时、参考答案正确率、错误原因和重做情况。
- 结构化教学步骤、数值计算校验、表格 / SVG / 原图展示、基础解法与快速解法、教学性质的命题分析。
- 答案冲突阻止教学内容发布；未经核验的来源不能自动认证为官方真题。
- 每日任务、间隔复习、知识覆盖、同考点题目和申论草稿功能。每日任务、申论材料和笔记依赖本地私人目录；公开版未附带这些内容，界面会显示缺失状态。
- `src/core/guokao.ts` 中的考试日期、每日时长是可调整的示例配置。学习计划生成工具位于 `scripts/build-guokao-catalog.py`，不是开箱附送的完整题库下载器。
- AI 为可选的 OpenAI 兼容接口；无密钥可使用本地学习功能。AI 教学内容需核验，不提供官方申论评分或通过率保证。

## 数据与隐私

这是仅绑定本机地址的单用户应用，没有公网账户与访问控制，不应直接部署为开放服务。

- `.env` 保存本地配置；仓库仅附空密钥示例 `.env.example`。
- `data/` 保存数据库、私人题库、目录、原图、笔记、草稿及归档。
- `uploads/` 保存上传原件；`artifacts/` 保存本地验收输出。
- 以上目录、数据库、日志、证书和私人密钥均由 `.gitignore` 排除。
- 不自动将文档发送给模型。使用 AI 功能前，应了解配置的服务商将处理所提交的题目内容。
- 本仓库以干净代码快照发布，不包含私人开发历史或个人邮箱。后续发布仍须检查实际暂存文件，不仅依赖忽略规则。

迁移自己的学习空间时，请单独备份 `data/`、`uploads/` 和 `.env`，不要上传到公开仓库。

## 开发与测试

```powershell
npm test
npm run typecheck
npm run build
```

通用逻辑测试可在空数据环境运行；依赖私人题库的测试会明确跳过。`npm run test:acceptance` 需要本机 Edge、运行中的服务及已准备的私人国考目录，不能把缺少题库的跳过项视为验收通过。

主要目录：

- `src/components/`：练习、教学、每日计划、知识与申论页面。
- `src/core/`：数据模型、知识体系、解析校验与学习统计。
- `src/server/`：数据库、来源文件、导入与模型接口。
- `prisma/`：SQLite 模型和迁移。
- `scripts/`：本地启动、资料整理与验收工具。
- `tests/`：计算、逻辑、数据边界与统计测试。

历史资料整理脚本仅用于用户合法持有的本地文件。公开可访问不等于获得再分发授权，请勿将未经授权的题目正文、答案解析和图片加入仓库。
